# Kanji Reading Lab

日本語学習者向けの、ブラウザで動作する漢字リーディングアプリです。

文章を読みながら漢字・熟語の読みを確認し、覚えた語のふりがなを少しずつ減らせます。学習状態、復習予定、読書ライブラリは利用者それぞれのブラウザ内（`localStorage`）に保存されるため、複数の利用者がお互いの単語帳へ干渉することはありません。

## 主な機能

- AIで整形した `[表記|ひらがなの読み|英語の意味]` 形式を読み込み
- AIを使わない内蔵熟語辞書・漢字辞書による読み支援
- 義務教育で扱う常用漢字2,136字の音読み・訓読みを内蔵
- 未注釈の単漢字は読みを断定せず、タップ後に候補を表示
- 漢字・音読み・訓読みから内蔵辞書を検索
- 漢字・熟語ごとの「覚えた」「復習が必要」を保存
- 読み方の手動選択・修正と、個人辞書への自動保存
- 簡易的な間隔反復による復習
- 読書ライブラリ、学習履歴、JSON入出力
- 日本語・英語・ロシア語・フランス語・スペイン語のUI
- 7日・30日・90日・削除しない、から本文保存期間を選択
- スマートフォン、タブレット、パソコン対応

## 読み方の優先順位

1. 学習者の個人辞書に保存された読み
2. AI形式で文章中に指定された読み
3. 内蔵の熟語辞書
4. 2,136字の音読み・訓読み辞書から利用者が選んだ候補

日本語の読みは熟語、送り仮名、文脈によって変わります。そのため、内蔵漢字辞書だけで文脈上の正しい読みを完全には決定しません。未確定の読みは本文にふりがなとして表示せず、点線と小さな印で示します。利用者が読みを選択・修正すると、その語はブラウザ内の個人辞書に保存され、次回の未注釈文章でも語単位で優先照合されます。

## 開発環境

- Next.js
- React
- TypeScript
- CSS
- KANJIDIC2から生成した2,136字の小型ローカル辞書
- 外部の形態素解析APIは不使用

辞書は実行時に外部へ接続せず、`app/data/school-kanji.json` を読み込みます。GitHub Actionsが毎月1回、EDRDGの公式データに更新がないか確認し、変更があればレビュー用のPull Requestを作成します。手動更新は `npm run dictionary:update` で実行できます。

辞書データの出典とライセンスは、アプリ内の「設定 → 辞書の出典とライセンス」および [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) に記載しています。

## ローカルで起動する

Node.js 22以降を用意して、次を実行します。

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開いてください。

## データと著作権

学習記録と本文はブラウザの `localStorage` に保存されます。標準設定では、本文だけを最後に読んでから30日後に削除します。学習した語、読み、復習記録は残ります。

利用者は、自分で利用する権利のある文章だけを入力してください。著作権に関する法律は国によって異なります。
